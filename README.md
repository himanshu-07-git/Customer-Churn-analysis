# Customer-Churn-analysis
Customer Churn Analysis 📊
Overview

This project focuses on analyzing customer churn behavior in a telecom company using Python. The analysis was performed using Exploratory Data Analysis (EDA) techniques and data visualization libraries to identify the major factors responsible for customer churn.

The project helps understand customer behavior patterns and provides business insights that can help telecom companies improve customer retention strategies.

Objectives
Analyze customer churn patterns
Identify factors affecting customer retention
Compare churn across different customer categories
Understand customer behavior using visualizations
Generate business insights and recommendations

Exploratory Data Analysis (EDA)
1. Churn Distribution
Analyzed overall churn percentage using countplots and pie charts.
Around 73% customers stayed with the company.
Approximately 27% customers churned.
Insight

Although most customers are retained, the churn percentage is still significant for business growth.

2. Gender-wise Churn Analysis
Compared churn behavior between male and female customers.
Insight

Gender did not show a major impact on churn behavior.

3. Senior Citizen Analysis
Created stacked percentage bar charts for churn comparison.
Insight

Senior citizens showed comparatively higher churn percentages than non-senior customers.

4. Tenure Analysis
Used histograms and boxplots to analyze customer tenure.
Insight

Customers with lower tenure had higher churn rates, while long-term customers were more loyal.

5. Contract Type Analysis
Compared churn across different contract categories.
Insight

Customers with month-to-month contracts had the highest churn percentage compared to yearly contracts.

6. Payment Method Analysis
Analyzed churn behavior based on payment methods.
Insight

Electronic check users showed higher churn rates compared to automatic payment users.

7. Service-wise Analysis

Multiple telecom services were analyzed using subplot countplots:

Phone Service
Multiple Lines
Internet Service
Online Security
Online Backup
Device Protection
Tech Support
Streaming TV
Streaming Movies
Insight

Customers without Online Security and Tech Support services showed higher churn percentages.

Key Business Insights
New customers are more likely to churn.
Long-term contracts improve customer retention.
Online Security and Tech Support services reduce churn.
Senior citizens require better customer support strategies.
Fiber optic internet users showed relatively higher churn behavior.
Business Recommendations
Improve onboarding experience for new customers
Promote long-term contracts
Encourage automatic payment methods
Improve customer support services
Provide personalized offers to high-risk customers
Improve fiber optic internet service quality
Conclusion

This project successfully identified important churn-driving factors using data analysis and visualization techniques. The analysis helps understand customer behavior and provides actionable insights that can support better business decisions and customer retention strategies.
